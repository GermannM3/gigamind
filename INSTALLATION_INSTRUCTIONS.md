# Инструкция по установке и тестированию GigaMind APK

`/home/germannm/Документы/gigamind/GigaMind-release.apk`

## Установка APK

### Вариант 1: На физическом устройстве Android

1. Скопируйте файл `GigaMind-release.apk` на ваше Android устройство
2. Откройте файл на устройстве
3. Следуйте инструкциям установщика
4. Если появится предупреждение о безопасности, разрешите установку из неизвестных источников

### Вариант 2: С помощью ADB

1. Убедитесь, что ADB установлен на вашем компьютере
2. Подключите Android устройство к компьютеру по USB
3. Включите режим разработчика и отладку по USB на устройстве
4. Выполните команду:
   ```bash
   adb install /home/germannm/Документы/gigamind/GigaMind-release.apk
   ```

### Вариант 3: На эмуляторе Android

1. Запустите эмулятор Android
2. Перетащите файл `GigaMind-release.apk` в окно эмулятора

## Возможные проблемы и решения

1. Если приложение не может подключиться к серверу:
   - Проверьте подключение к интернету на устройстве
   - Убедитесь, что сервер доступен по указанному адресу
   - Проверьте настройки брандмауэра

2. Если установка APK блокируется:
   - Разрешите установку из неизвестных источников в настройках безопасности устройства
   - Используйте ADB для установки

3. Если приложение крашится при запуске:
   - Убедитесь, что ваше устройство соответствует минимальным требованиям (Android 6.0+)
   - Попробуйте переустановить приложение
