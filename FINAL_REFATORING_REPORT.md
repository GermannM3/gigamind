## 🚀 Инструкции по запуску

### Запуск сервера GigaMind
1. Установите зависимости:
   ```bash
   python -m venv venv
   source venv/bin/activate  # Linux/Mac | Windows: venv\Scripts\activate
   pip install -r requirements-light.txt
   ```

2. Настройте переменные окружения:
   Создайте файл `.env` на основе `.env.example` и укажите свои данные для GigaChat API.

3. Запустите сервер:
   ```bash
   python main.py api
   ```

4. API будет доступен по адресу: http://127.0.0.1:8000

### Установка мобильного приложения
1. Скопируйте APK файл на Android устройство:
   `GigaMindMobile/android/app/build/outputs/apk/release/app-release.apk`

2. Откройте файл на устройстве и следуйте инструкциям установщика

3. Запустите приложение и начните диалог с AI-ассистентом
