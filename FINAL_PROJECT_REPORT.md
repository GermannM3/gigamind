## ▶️ Как запустить проект

### Запуск сервера GigaMind

1. **Установка зависимостей**:
   ```bash
   python -m venv venv
   source venv/bin/activate  # Linux/Mac | Windows: venv\Scripts\activate
   pip install -r requirements-light.txt
   ```

2. **Настройка переменных окружения**:
   Создайте файл `.env` на основе `.env.example` и укажите свои данные для GigaChat API.

3. **Запуск сервера**:
   ```bash
   python main.py api
   ```

4. **Доступ к API**:
   - API будет доступен по адресу: http://127.0.0.1:8000
   - Документация API: http://127.0.0.1:8000/docs
   - Веб-интерфейс: http://127.0.0.1:8000/ui

### Запуск веб-интерфейса

1. **Запуск приложения**:
   ```bash
   python main.py
   ```

2. **Открытие в браузере**:
   Перейдите по адресу: http://127.0.0.1:7860

## 📱 Мобильное приложение

### APK файл

Мобильное приложение успешно собрано и доступно в виде APK файла:

- **Файл**: `GigaMindMobile/build/outputs/apk/release/GigaMind-release.apk`
- **Размер**: ~39 МБ
- **Версия**: 1.0.0
- **Архитектура**: Универсальная (ARM и x86)

### Установка APK

Вы можете установить APK следующими способами:

1. **На физическом устройстве Android**:
   - Скопируйте файл на устройство
   - Откройте файл и следуйте инструкциям установщика

2. **С помощью ADB**:
   ```bash
   adb install GigaMindMobile/build/outputs/apk/release/GigaMind-release.apk
   ```

3. **На эмуляторе Android**:
   - Запустите эмулятор
   - Перетащите APK файл в окно эмулятора

## ⚙️ Особенности реализации

- **GigaChat API** - используется для генерации ответов
- **SQLite** - локальное хранение истории взаимодействий
- **FAISS** - векторный поиск по истории запросов
- **VADER Sentiment** - анализ тональности для самооценки
- **Gradio** - веб-интерфейс для взаимодействия
- **React Native** - мобильное приложение
- **FastAPI** - REST API для мобильного клиента
